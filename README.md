# ポートフォリオサイト（学習用サンプル）

プログラミング初心者・未経験者の「最初の1本」として作る、
HTML / CSS / JavaScript だけのポートフォリオサイトです。
ライブラリやビルドツールは一切使っていないので、ファイルを置くだけで動きます。

架空の人物「佐藤 はるか」を題材にしたサンプルです。
自分用に使うときは、文章・名前・リンクを書き換えてください。

## 主な機能

- 🌙 **ダークモード切替** — 右上のボタンで切替。選んだ設定はブラウザに記憶される
- ✨ **スクロールアニメーション** — 各セクションが画面に入るとふわっと表示
- 📱 **スマホ対応メニュー** — 狭い画面ではハンバーガーメニューに変化

## ファイル構成

```
mypf-sample/
├── index.html        … ページ本体（文章はここを編集）
├── css/style.css     … 見た目（色やレイアウト）
├── js/main.js        … 動き（3つの機能）
├── assets/favicon.svg… タブに出るアイコン
└── README.md         … このファイル
```

## ローカルで確認する

### かんたんな方法
`index.html` をダブルクリックしてブラウザで開くだけです。

### おすすめの方法（簡易サーバーを使う）
本番に近い形で確認できます。ターミナルでこのフォルダに移動して実行します。

```bash
python3 -m http.server
```

ブラウザで <http://localhost:8000> を開いてください。
止めるときはターミナルで `Ctrl + C` を押します。

## GitHub Pages で公開する

無料でインターネットに公開できます。

1. GitHub で**公開（Public）リポジトリ**を新規作成する
2. このフォルダの中身（`index.html` など）をリポジトリの**ルート**に置いて push する
3. リポジトリの **Settings → Pages** を開く
4. **Source** を `Deploy from a branch`、ブランチを `main`、フォルダを `/ (root)` に設定して Save
5. 数分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

> ファイルの読み込みはすべて相対パス（`css/style.css` など）なので、
> サブフォルダ付きのURLでも表示が崩れません。

## カスタマイズのヒント

| 変えたいもの | 編集する場所 |
|---|---|
| 名前・自己紹介・作品の文章 | `index.html` |
| 色（テーマカラー） | `css/style.css` の先頭にある `:root` / `[data-theme="dark"]` の変数 |
| スキルバーの数値 | `index.html` の `style="--w:90%"` の数字 |
| SNSリンク | `index.html` の `social-list` 内の `href` |
