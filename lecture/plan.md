# 講義「【ゼロから学ぶ】Claude Code × Cursor 完全入門 ─ AI駆動開発 はじめの一歩」構成プラン

## Context（なぜ・何を・誰のために）

完全初心者向けに、Claude Code と Cursor を「知る → 入れる → 使う → 公開する」まで一気通貫で
体験させる **約90分の収録型講義動画**を作る。題材は HTML/CSS/JS のみのポートフォリオサイトで、
**Claude Code にゼロから作らせ、GitHub Pages で世界に公開する**ところがゴール。

この計画では、講義の**章立て・各章で話す内容・デモ内容・つまづき対策**を確定し、
最終成果物として **PowerPoint(.pptx)スライド（スピーカーノート付き）** を作る指針を定める。
.pptx は Google Slides にインポートして仕上げる。操作動画（画面収録）は別途収録し、
該当箇所に差し込む。

### 確定した前提（ヒアリング結果）

| 項目 | 内容 |
|---|---|
| 受講者 | プログラミング完全未経験〜HTML/CSSを少し触った初学者（現役エンジニアは対象外）。最も初心者に合わせる |
| 形式 | 収録動画。スライド解説 ＋ 画面収録デモを合成 |
| 時間 | 約90分（「程度」＝多少前後可） |
| OS | Mac で実演、Windows は補足ボックスで対応 |
| ツールの位置づけ | 主役は **Claude Code**。Cursor は「エディタ環境＋Claude Codeを動かす器」。Cursor自身のAIは**タブ補完のみ実用**、他機能は紹介に留める |
| デモ題材 | Claude Code に**ゼロからポートフォリオサイトを生成**させる |
| ゴール | ツール導入 → AIに指示して動かす → **GitHub Pages で公開**まで |
| アカウント/料金 | 登録手順も料金も**丁寧に**説明 |
| Git | 難しいので **main ブランチ1本**で進める。ブランチの説明は軽く触れる程度、深追いしない |

### 調査の一次ソース（2026-05-20 時点・公式確認済み）

- Claude Code: https://code.claude.com/docs/en/overview, /setup, /quickstart, /permission-modes, /memory, /best-practices, /vs-code
- 料金: https://claude.com/pricing （Claude Code は Pro/Max/Team/Enterprise に含まれる。**無料プランでは使えない**）
- Cursor: https://cursor.com, https://cursor.com/docs, /docs/tab/overview, https://cursor.com/pricing
- **重要な発見**: Cursor に「Claude Code 拡張機能」(`anthropic.claude-code`) を入れると **CLI も同梱**される
  → 初心者は Node.js やターミナルのインストールコマンドに触れずに済む。これを環境構築の軸にする。

## 全体構成（90分・6章＋付録）

| 章 | 時間 | ねらい |
|---|---|---|
| 0. オープニング | 6分 | 完成形を先に見せ、ゴールと全体像を共有 |

| 2. 環境構築 | 24分 | 3アカウント・インストール・料金。最大のつまづき所を丁寧に |

## 章ごとの詳細（スライド構成・話す要点・デモ・つまづき）

凡例: 🎬＝画面収録デモ差込 / ⚠️＝つまづき注意として明示する点

### 第0章 オープニング（6分）
- S1 タイトル（講義名・講師名）
- S2 この講義のゴール（「ツールを入れる／AIに作らせる／ネット公開する」の3点を明示）
- S3 🎬 **完成形を先に見せる** ＝ 公開済みポートフォリオ（本デモの成果物。冒頭に配置）
- S4 「AI駆動開発」とは（1枚でやさしく：人が指示し、AIが手を動かして開発する）
- S5 今日の流れ（6章アジェンダ）
- 話す要点: 「コードが書けなくても、今日この90分でサイトを作って公開できる」と安心と期待を与える

### 第1章 Claude Code と Cursor とは（10分）
- S6 章扉
- S7 「コードを書く場所」＝エディタとは（メモ帳との違い、超初心者向け）
- S8 Cursor とは（VS Code ベースの AI コードエディタ。「作業場」）
- S9 Claude Code とは（エージェント型コーディングツール。「指示すると自分でファイル編集・コマンド実行まで進めるAI」）
- S10 チャット型AI vs エージェント型AI の違い（図：答えるだけ／手を動かす）
- S11 2つの関係（Cursor＝作業場、Claude Code＝その中で働くAI。今日はCursorにClaude Codeを入れる）
- S12 用語ミニ辞典（ターミナル／拡張機能／リポジトリ／GitHub Pages）
- 話す要点: 名前が似て紛らわしいので「役割が違う」ことを繰り返す。⚠️CursorとVS Codeは見た目そっくりだが別アプリ

### 第2章 環境構築（24分）— 最重要・最つまづき
- S13 章扉
- S14 **必要な3つのアカウント**（①Cursor ②Claude(Anthropic) ③GitHub）。なぜ3つ要るかを1枚で
- S15 🎬 Cursor をインストール（Mac: 公式サイト→.dmg→Applicationsへ）＋ ⚠️Windows補足ボックス（.exe）
- S16 🎬 Cursor 初回起動・サインイン（＝Cursorアカウント作成）
- S17 （補足）VS Code 経験者は設定インポート（Cmd/Ctrl+Shift+J → Account）
- S18 料金①: **Cursor は無料(Hobby)プランでOK**（今回AIはタブ補完中心のため）
- S19 料金②: **Claude Code は無料では使えない** → **Claude Pro が必要**（月$20 / 年契約は実質$17/月）。Maxは上位。⚠️為替で円換算は変動、当日要確認
- S20 🎬 Cursor に「Claude Code 拡張機能」をインストール（拡張ビューで "Claude Code" 検索）。CLI同梱なのでNode.js等の準備不要
- S21 🎬 Claude Code パネルを開いてサインイン（＝Claude/Anthropicアカウント。ここでClaude Proに加入）
- S22 ⚠️よくあるつまづき: **サインインが2種類**（Cursor用とClaude用は別物）／拡張が出ない時はウィンドウ再読込／Mac/Winでインストーラが違う
- S23 環境構築チェックリスト（ここまで出来たか確認）
- 話す要点: 料金は逃げずに正直に。「最低限かかるのは Claude Pro の月$20。Cursor も GitHub も無料」と総額像を明示

### 第3章 Cursor をさわってみる（8分）
- S24 章扉
- S25 🎬 フォルダを開く・エディタ画面の見方（ファイルツリー／エディタ／パネル）
- S26 🎬 **タブ補完(Tab)を体験**（ゴーストテキスト→Tabで承認／Escで却下）。AIの「魔法感」を見せる山場
- S27 他機能は紹介のみ: Ask（コードに質問）／Agent（Cursor版エージェント）／Cmd-K（その場編集）。「今日はClaude Codeを主に使う」と整理
- S28 🎬 ターミナルの開き方（後半で使う場所だけ見せる）
- 話す要点: ⚠️タブ補完が「うるさい」と感じたら右下から一時停止できる、も一言

### 第4章 Claude Code でポートフォリオをゼロから作る（26分）— 本番
- S29 章扉「今から作るもの」（完成イメージ再掲）
- S30 🎬 作業フォルダを用意し Cursor で開く
- S31 プロンプトの基本（親切な同僚に話すように・具体的に。良い例/悪い例）
- S32 🎬 最初の指示を出す（例文を提示。例:「HTML/CSS/JSだけで、自己紹介・スキル・作品・連絡先のあるポートフォリオサイトを作って」）
- S33 🎬 **いきなり作らせない「プランモード」**（まず計画させ、内容をレビューして承認）。探索→計画→実装の考え方
- S34 🎬 **権限承認のしくみ**（ファイル作成やコマンド実行の前に確認が出る＝勝手に動かないので安心）
- S35 🎬 ブラウザでプレビュー確認
- S36 🎬 対話で直す①（追加依頼。例:「ダークモード切替を付けて」「配色を変えて」）— AIと往復して仕上げる感覚
- S37 🎬 対話で直す②（うまくいかない時: Escで停止／「やっぱり戻して」／`/rewind`で巻き戻し）
- S38 🎬 CLAUDE.md と `/init`（プロジェクトのルールをAIに覚えさせる。毎回説明しなくて済む）
- S39 `/clear` でコンテキスト整理、の一言
- S40 🎬 ここまでの成果（完成したポートフォリオ）
- 話す要点: ⚠️思い通りにならない時に「怒らず、具体的に伝え直す／戻す」のが初心者のコツ。検証手段（ブラウザで見る）を必ず挟む

### 第5章 GitHub Pages で公開する（12分）
- S41 章扉
- S42 🎬 GitHub アカウントを作る（3つ目のアカウント）
- S43 Git / GitHub とは（超ざっくり「変更を記録・共有するしくみ」）。⚠️**ブランチは軽く一言だけ**（枝分かれして作業する仕組み。今日は main 1本でいく、深追いしない）
- S44 🎬 リポジトリを作ってサイトをアップ（Claude Code に「GitHubに公開して」と頼む or 手順を提示。main ブランチのみ）
- S45 🎬 GitHub Pages を ON（Settings → Pages → Deploy from a branch / main / root）
- S46 🎬 公開URLにアクセス！（冒頭で見せた完成形が世界に公開された）
- S47 ⚠️つまづき: 反映に数分かかる／ブラウザキャッシュで古い表示 → ハードリロード（Cmd/Ctrl+Shift+R）
- 話す要点: 「これであなたのサイトが世界中から見られる」と達成感を演出

### 第6章 コツ・次の一歩・まとめ（4分）
- S48 うまく使う5つのコツ（①具体的に指示 ②まず計画させる ③検証手段を渡す ④こまめに軌道修正・`/clear` ⑤CLAUDE.mdを育てる）
- S49 次の一歩（存在紹介のみ: スキル／サブエージェント／MCP／Hooks ＝「もっとできることがある」）
- S50 まとめ（今日できるようになったこと）＋ おわりに（エール・公式ドキュメント等の学習リンク）

### 付録スライド（動画では使わず資料として添付 / 概要欄リンク用）
- A1 よくあるつまづき一覧（2種類のサインイン、無料枠制限、拡張が出ない、Pages反映遅延 ほか）
- A2 用語集
- A3 参考リンク（公式ドキュメントURL一式）

## 成果物と作り方

1. **スライド本体 = PowerPoint(.pptx)**
   - `python-pptx` で生成（実行前に未導入なら `pip install python-pptx`）
   - 各スライド: 見出し＋要点（箇条書き）＋ **スピーカーノートに「話す内容（要点＋補足文）」** を記載
   - 🎬 のスライドはノートに**デモ操作手順（収録台本）**も記述
   - デザイン: 初心者向けに大きめ文字・1スライド1メッセージ・余白多め。画面収録を貼る所はプレースホルダ枠
   - 完成後 Google Slides へ: Drive にアップ→「Googleスライドで開く」、または スライド→ファイル→インポート
2. **デモ収録台本**: 各 🎬 スライドのスピーカーノート内に手順を箇条書き（Mac基準、Windows差分を注記）。章4・5は一連の流れなので通し台本として整理
3. **付録資料**: つまづき一覧・用語集・参考リンクは配布資料／動画概要欄用

## 実装ステップ（このプラン承認後）

1. 章ごとのスライド文言とスピーカーノートを全文執筆（日本語・初心者トーン）
2. デモ収録台本を章4・5中心に確定
3. `python-pptx` で .pptx を生成（スピーカーノート込み）
4. 価格・インストール手順を公式ページで最終確認し数字を反映
5. .pptx を納品 → ユーザーが Google Slides にインポートして体裁調整・収録

## 検証（録画前のチェック）

- **タイムキーピング**: スライドを通しで読み上げ、各章が時間内か計測。超過章は第3章/第6章を圧縮、または2本に分割
- **.pptx 互換**: 生成した .pptx を実際に Google Slides にインポートし、レイアウト・ノートが崩れないか確認
- **デモ実機リハーサル**: Mac で台本通りに「インストール→拡張→生成→公開」を一度通し、つまづき箇所が台本と一致するか検証してから本収録
- **情報の鮮度**: 収録当日に Claude Code / Cursor の価格・インストール手順・拡張機能名を公式で再確認
- **初心者レビュー**: 可能なら完全初心者1名に通し視聴してもらい、用語・手順の不明点を洗い出す
